# 🌍 Climate Change Data Analysis Project

## 📌 Project Overview
This project focuses on analyzing climate change data using Python to identify environmental trends, climate risks, and the relationship between factors such as CO₂ emissions, temperature changes, sea level rise, and extreme weather events.

The project includes data cleaning, exploratory data analysis (EDA), statistical testing, correlation analysis, and data visualization to generate meaningful environmental insights.

# 📊 Questions Solved in This Project

## 1️⃣ What is the size of the dataset?
- Identified the number of rows and columns in the dataset.

## 2️⃣ What are the columns present in the dataset?
- Extracted all feature names and dataset structure.

## 3️⃣ Are there any missing values?
- Checked and analyzed null/missing values in the dataset.

## 4️⃣ Are there any duplicate records?
- Identified duplicate entries and verified data quality.

## 5️⃣ Which countries are included in the dataset?
- Extracted and analyzed countries available in the climate dataset.

## 6️⃣ What is the correlation between climate factors?
- Performed correlation analysis between:
  - CO₂ Emissions
  - Global Temperature
  - Sea Level Rise
  - Extreme Weather Events

## 7️⃣ Which countries have high renewable energy usage and low CO₂ emissions?
- Compared renewable energy usage with emission levels.

## 8️⃣ How is global temperature changing over time?
- Analyzed global temperature trends using visualizations.

## 9️⃣ Which countries produce the highest CO₂ emissions?
- Identified top CO₂ emitting countries.

## 🔟 How can climate risk scores be calculated?
- Created a climate score based on environmental factors.

## 1️⃣1️⃣ Which countries are at high climate risk?
- Categorized countries into climate risk levels.

## 1️⃣2️⃣ Which factors affect climate score the most?
- Found key influencing factors using correlation analysis.

### Key Findings:
- Avg Temperature → +0.46
- Extreme Weather Events → +0.45
- Sea Level Rise → +0.41
- CO₂ Emissions → +0.37

## 1️⃣3️⃣ Is there a statistical difference between high-risk and low-risk countries?
- Applied T-Test analysis to compare climate risk groups.

## 1️⃣4️⃣ Which countries have the highest and lowest climate scores?
- Ranked countries based on calculated climate score.

## 1️⃣5️⃣ How do CO₂ emissions vary across countries?
- Visualized country-wise CO₂ emission patterns.

## 1️⃣6️⃣ What are the key environmental factors for countries?
- Identified important climate indicators for analysis.

# 🎯 Key Insights
- Rising temperatures and extreme weather events strongly impact climate risk.
- Countries with higher renewable energy usage generally show lower CO₂ emissions.
- Climate scores help identify environmentally vulnerable countries.
- Statistical testing confirmed significant differences between high-risk and low-risk countries.
